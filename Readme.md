# SmartTicket

AI-powered customer support ticket analyzer built with Python, Flask, and Machine Learning.

## Features

* Analyzes customer support tickets
* Predicts ticket category
* Detects priority and sentiment
* Recommends support team
* Shows prediction confidence

## Tech Stack

* Python
* Flask
* Scikit-learn
* Pandas
* HTML
* CSS
* JavaScript

## Machine Learning

TF-IDF + Logistic Regression
